# ClipDeck 预览 4：从这里开始

适合把访谈、课程、播客和口播的多个素材剪成一段完整故事。你挑选想保留的话，软件保留对应视频；下面的片段可以任意排序。

## 先看真实示例

在 [预览 4 下载页](https://github.com/lsj0914/clipdeck/releases/tag/v0.1.0-preview.4) 下载程序。先看 **USGS-first-response-final.mp4**：这是有真实人物和画面的 116.8 秒访谈成片。

再下载 [可编辑示例 ZIP](https://github.com/lsj0914/clipdeck/releases/download/v0.1.0-preview.3/ClipDeck-USGS-demo-20261007.zip)，完整解压，保留里面的工程和素材文件夹。打开 ClipDeck，点“打开”，选择 **USGS-first-response.clipdeck**。它含 3 个访谈素材、带断句的原文和 12 个交错排列的片段。已有转写可以直接剪，无需先准备识别模型。

如果收到完整本地交付文件夹，其中已附 **ClipDeck.app**、**demo/USGS-first-response.clipdeck** 和成片；从公开下载页获取程序时，请另外下载并完整解压上面的示例 ZIP。

## 剪自己的视频

1. 点左侧“导入视频”，选自己的文件。素材可以有多份；点左侧素材切换原文。
2. 有讲话时，打开“转写设置”或底部“设置本地转写”，确认语言与模型。首次需要明确准备识别模型；可下载所选模型，或选择已准备好的对应模型文件夹。Small 较小，Large v3 turbo 是可选项。准备完成后开始转写，进度里可取消；重新转写时原有结果保留到新结果成功。没有讲话时切换“按时间”，设置起止位置。
3. 点击一个词定位，按住 Shift 点击末尾扩选，或双击选择一段。先“试听”检查边界，再点“加入成片”。选区也可“校正文字”，纠错保留时间位置。人名、术语和“时间需核对”的词应对照原视频检查。
4. 底部每张卡片是一段成片。拖动卡片、使用前移/后移按钮调整顺序；原视频的后半段可以放到成片前面。右侧“切点检查器”微调入点、出点。撤销和重做可恢复编辑。
5. 点“预览成片”准备连续预览。修改剪辑后需准备对应的新预览；同一已完成预览可重用缓存。打开“任务进度”查看实际状态，耗时受视频格式、长度和电脑影响。
6. 播放器上方选 **成片**，点击底部片段跳到它在成片中的起点；点原文中的词跳到它在成片中的对应位置。选 **原素材** 时，按原视频定位。没有加入成片的文字会提示，保持当前视频；同一句重复使用时优先定位所选片段。
7. 点 **放大**，占满窗口检查画面。按 Esc 返回剪辑并保留播放位置。确认后选画幅、点“导出视频”，从系统保存窗口选择新的输出文件。完成后在“任务进度”打开导出的成片，放大播放核对。
8. 点“保存”保存 `.clipdeck` 工程，和原始视频一起保管。工程引用素材，不把原视频装进去。

## 素材移动或内容改变

移动了视频，点“重新关联素材”选回对应原文件。重新关联相同内容会恢复原文和切点；相同时长但内容不同的视频会被标为已变化，旧原文失效，旧片段需要复核，阻止直接导出。把工程复制到新的位置后，可能需要重新选择素材，授权只属于相应工程。

剪辑和导出保留原文件。公开示例使用 USGS 可公开素材；你的私人视频、转写和工程不会进入公开示例。

## 这版的边界

程序是 Apple Silicon Mac 实验性预览，使用临时签名，尚无 Apple Developer ID 签名与公证。若系统拒绝打开下载的程序，请使用公开源码构建路线；不要关闭系统安全保护。macOS 14 实际运行、Intel Mac、Windows、Linux 尚未验证。

转写会生成标点与分段，识别结果仍需核对。软件目前不自动烧录字幕，不保证所有口音、人名、术语都准确。具体已测流程和限制见 [预览 4 验证记录](https://github.com/lsj0914/clipdeck/blob/main/docs/verification/preview-4.md)。
