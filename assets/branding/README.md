# Original ClipDeck mark

The ink tile, stacked paper cards and amber editing cut were authored for ClipDeck. No external image or font is used. These assets share the application's GPL-3.0-or-later license.

`clipdeck-mark.svg` is the editable vector. `clipdeck-icon.png` is the 1024px preview. `ClipDeck.icns` contains native macOS icon sizes. To regenerate from the matching geometry, run `swift scripts/packaging/generate_icon.swift /PATH/TO/NEW_DIRECTORY` on macOS with command-line tools, then inspect the preview before replacing tracked assets. The generator refuses existing output directories.
